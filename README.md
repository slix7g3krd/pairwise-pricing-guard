# pairwise-pricing-guard

商城下单接口接受客户端传价格后，业务逻辑篡改就能把商品买成负数：单价直接采信前端；数量允许负数和零；优惠券叠加没有上限；折扣顺序按客户端传的顺序算；币种不校验，USD 当 CNY；运费和税费由客户端填；四舍五入在行级和总级各算一次，出现一分钱差额；退款金额按原价而不是实付；赠品不计库存；总价没有服务端重算。security/pricing_guard.py 是核心，tests/test_pricing_guard.py 15个红。要修的是：价格服务端取；数量正数校验；券叠加上限；折扣顺序固定；币种一致；运费税费服务端算；统一舍入；退款按实付；赠品扣库存；总价重算。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
